A WordPress theme for automotive dealer sites.

== Description ==

ShopperExpress serves vehicle inventory (new and used listings), offers (finance, lease, service,
conditional) and flexible content pages. Vehicle data can come either from WordPress content (ACF
fields on custom post types) or live from the dealer's Intice Nexus feed, switchable per site.

Built on ACF PRO for content modeling and Gutenberg blocks for flexible pages. Includes an
Operation Center admin dashboard for system status, API health, lead delivery, and SEO/structured
data settings.

== Requirements ==

* PHP 8.1 or newer
* WordPress 5.0 or newer
* ACF PRO 6.x or newer (the theme shows an admin notice if it is not active)
